== Design log
- Primary outcome fixed before any result was seen: whole-day realized variance from 5-minute returns (rv5), 6-month windows, the DiD at event c. Everything else is secondary.
- Expiry dates come from the bhavcopies (an expiry happened on d if options expiring on d trade on d; monthly if an index future also expires on d). Before the first bhavcopy (20 Oct 2022) a Thursday rule with holiday roll-back is used; it reproduces every bhavcopy expiry date on the overlap (see stdout).
- Changed: the rule first labelled the last expiry *date* of a month as monthly, which mislabels a 1st-of-month Thursday holiday rolled back into the previous month (found by the overlap check, e.g. 30 Apr 2025). The rule now uses the last *scheduled* Thursday of the month.
- Long sample starts 4 Mar 2019 because Nifty weekly options are generally reported to start in February 2019 (not verifiable from our files). Pre-Oct-2022 data are used only for event a's 12-month pre-window (Sep to Oct 2022), placebo dates and the regime R0 description.
- Weeks with a monthly expiry of either index are excluded from the main samples: event b changes only monthly weeks (analysed separately), and after event c Bank Nifty still has a monthly expiry, which would put a Bank Nifty expiry inside the 'no weekly' weeks. Weeks where any expiry was moved by a holiday are also excluded (target weekday is then a holiday or a double expiry day).
- Volume is measured as turnover in rupees (premium and notional), not contracts, because lot sizes changed several times (read from the UDiFF files; inferred for the legacy layout).
- Changed: the moving-block bootstrap under-weights the first and last weeks of a window; with 15 to 20 weeks per side this visibly shifted intervals (e.g. a difference of -0.01 had an interval of -0.26 to 0.67 in a trial run). Replaced by the circular block bootstrap (blocks of 4 weeks).
- Changed: with very few weeks (event b's monthly weeks: 3 to 7 per side) a 4-week block equals the whole sample, so every circular draw had the same mean and the interval collapsed to a point. The block length is now capped at a quarter of the sample (iid resampling for 7 weeks or fewer).
- Changed: randomization inference over placebo dates uses the Welch t statistic (studentized, so periods with different noise are comparable) and is reported only when the placebo windows contain at least 3 non-overlapping windows. With 12-month windows only about 2 fit in the 2019 to 2023 quiet period and the placebo t statistics had a standard deviation near 0.6 (too narrow), which made p-values look far too small.
- Friday was planned as a negative-control weekday because no NSE rule change in this study targets it. It turned out not to be clean: Friday premia moved at events a and d about as much as treated weekdays, and BSE's Sensex weekly options are reported to have expired on Fridays in 2023 and 2024 (BSE files are not in this repository, so this is unverified). The calibration table reports how often each test rejects for Friday; we use it to judge which tests are too liberal.
- Added (data fact from the coordinator, checked in the bars): from 3 Aug 2026 NSE sets the official close in a closing auction, so the Nifty minute index is frozen for about 13 minutes before 15:28 to 15:29 and then jumps. The script detects this (every day from then on has >= 8 flat bars in the last 20 minutes) and treats it as event e: regime R3 and event d's windows stop at e, and the auction days are reported separately (R4) and in 'kept' variants. Bank Nifty bars end in April 2026, before e.
- The daily return correlation is one number per day, so it is not used in DiDs that compare the same weekday of both indices (it would cancel exactly).
- Changed: a table splitting the extra variance into first-hour and last-hour shares was dropped because the whole-day excess is close to zero, so the shares were ratios of noise. Replaced by log premia per part of the day (first hour, 10:15 to 14:30, last hour, last 30 minutes).
- Added after seeing results (post hoc, labelled as such): the frequency diagnostics rv1/rv5 and RS/rv5, because the per-minute Rogers-Satchell premium differed from the 5-minute RV premium.

Total run time 115s.
